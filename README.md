## Getting Started (Local Development)

```bash
# Clone the repository
git clone https://github.com/Umwizer/<repo-name>.git
cd <repo-name>

# Install dependencies
npm install

# Run the development server
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

> Adjust the commands above if the project uses a different package manager (`yarn`, `pnpm`) or framework setup.
