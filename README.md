# Ruth Umwizerwa | Portfolio

Personal portfolio of Ruth Umwizerwa, a Software Engineering student at AUCA, Kigali.

**Live site:** https://ruthumwizerwa.netlify.app/ ,https://ruthumwizerwaportfolio.vercel.app

## Features
- Responsive, single-page design
- Sections for experience, skills and selected projects
- Links to GitHub, LinkedIn and CV

## Tech stack
Next.js · TypeScript · Tailwind CSS · deployed on [Netlify/Vercel]

## Run locally
git clone https://github.com/Umwizer/ruthumwizerwaportfolio
cd ruthumwizerwaportfolio
npm install
npm run dev

Open http://localhost:3000
